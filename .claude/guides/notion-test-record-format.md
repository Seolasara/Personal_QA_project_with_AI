# 노션 테스트 기록 형식
대상: 노션 "테스트 실행" DB(`collection://de613125-b2b2-40af-842a-9f1265e9376c`)와 "이슈 검수" DB(`collection://beb91aef-0900-4169-95f4-4bbbedc2d1fc`). `/test-run`이 실행 행을 만들고, `/test-triage`가 본문과 이슈 행을 채운다. 문체는 전역 "문서 문체"를 따른다.

## 1. 원칙
- 속성은 목록에서 훑어보는 용도라 짧게 쓰고, 자세한 내용은 본문에 쓴다. 속성에 쓴 정보는 본문에도 다시 쓴다.
- 서로 오갈 수 있게 연결한다. 실행 ↔ 이슈는 관계 속성과 본문 멘션으로, 백로그는 GitHub 링크로, Slack은 실행 스레드로 잇는다.
- 근거는 한 줄에 몰아 쓰지 않고 항목별 불릿으로 나눈다.

## 2. "테스트 실행" 행
- 속성: 실행(`YYYY-MM-DD HH:MM 전체 실행`), 실행 일시, 커밋, UI 결과, API 결과, 통과 수, 전체 수, 실패 수, xfail 수, 진행 상태, Slack, 보관 경로, 이슈(관계)
- 본문
  1. 요약: 전체 N개 중 통과 N, 실패 N, xfail N. 실패를 리포트 그룹별 건수로 한 줄
  2. 통과 현황: UI, API마다 대분류별 `통과/전체`(실패, xfail 건수). 대분류는 시트 TC의 대분류
  3. 실패 현황: TC마다 하위 불릿으로 사라 분류, 원인 요지, 이슈(이슈 검수 행 멘션), 백로그(GitHub 링크)
  4. xfail: 유지 건수, XPASS 건수, 상태가 바뀐 것
  5. 근거와 자료: `triage-report.md` 경로, HTML 리포트 위치(Slack 스레드), 커밋

## 3. "이슈 검수" 행
- 속성: `test-triage` 8번의 속성. "근거" 속성은 한 줄 요약(` / `로 3개 이내)으로 쓰고 끝에 "(상세는 검토 메모 2번)"을 붙인다.
- 본문은 두 부분이다. 사용자가 노션에서 보고 승인한 내용이 그대로 Jira에 올라가게 하려는 구조다.

### 3-1. Jira 초안 (사라 분류가 real-bug이거나, 판단에 따라 real-bug가 될 수 있는 안건만)
- `# Jira 초안` 제목 아래에 `.claude/guides/jira-issue-format.md` 3번의 9개 섹션을 같은 순서로 쓴다. 섹션 제목과 문체는 그 가이드와 샘플 QA-4를 따른다.
  1. `## [요약]` 2. `## [테스트 환경]` 3. `## [사전조건]` 4. `## [재현순서]` 5. `## [기대결과]` 6. `## [실제결과]` 7. `## [스크린샷/로그]` 8. `## [중요도]` 9. `## [참고]`
- 이슈 제목 속성이 Jira 제목이다.
- `/issue-register`는 이 부분을 고치지 않고 옮긴다. 노션 이미지는 본문으로 옮겨지지 않아서 [스크린샷/로그]에 보관본 경로를 적고, `/issue-register`가 그 파일을 Jira 첨부로 올린다.

### 3-2. 검토 메모 (모든 행)
- `# 검토 메모` 제목 아래에 쓴다. Jira에는 올리지 않는다.
  1. 분류: 사라 분류(확신도), 리포트 그룹, 백로그 링크, 테스트 실행 멘션
  2. 근거: 항목마다 한 불릿(실패 위치, 실패 메시지, 스펙, 원인 추정과 추정 표시, 확인 일시와 보관 경로)
  3. 판단 요청 또는 처리: 고를 수 있는 선택지와 추천, 이미 수리했으면 수리 내용과 커밋
- Jira 초안이 없는 행(test-bug, flaky, 일반 안건)은 검토 메모 앞에 요약, 기대결과와 실제결과, 증거(스크린샷, 로그)를 둔다.

## 4. 스크린샷 올리기
1. `notion-create-file-upload`로 `filename`(ex: `UI_13-test-failed-YYYY-MM-DD.png`)을 넣어 업로드 주소와 헤더를 받는다.
2. `curl -s -X POST "<upload_url>" -H "authorization: <헤더 값>" -F "file=@<보관본 png 경로>"`로 올린다. 헤더 값은 출력하지 않는다.
3. `notion-create-attachment`에 `source_file_id`를 넣고, 받은 `<image src="file-upload://...">`를 Jira 초안의 [스크린샷/로그](없으면 증거 섹션)에 넣는다. 업로드는 한 시간 안에 페이지에 붙여야 남는다.
