### #7 배송지 자동채움과 폼 입력 사이 race condition
- 문제 정의: UI 결제의 Billing Address 자동채움과 우편번호 자동조회가 폼 입력과 겹쳐 입력값이 덮어써질 수 있다.
- 발생 배경: UI 결제 테스트에서 간헐 실패. `networkidle`과 로딩 대기로 우회 중이다.
- 추정 원인과 근거: 프론트엔드 타이밍 문제로 추정하며 근본 원인은 미확인이다.
- 분류와 상태: timing(프론트엔드 race) / 대기 처리로 우회 중 / 발견 날짜 미상, 마지막 확인 2026-10-08 분류

### #8 계정 잠금(423) 해제 방법
- 문제 정의: 로그인 3회 실패로 잠긴 계정은 올바른 비밀번호로도 풀리지 않고, 시간 기반 자동 해제가 없다. `PATCH /users/{userId}`로 `failed_login_attempts: 0`을 설정해야만 풀린다.
- 발생 배경: 로그인 테스트 설계 중 확인. UI/API 테스트 계정을 customer2/customer3로 분리한 이유다.
- 추정 원인과 근거: `UserService.php`의 `MAX_LOGIN_ATTEMPTS=3`이고 잠금 체크가 비밀번호 검증보다 먼저 실행된다. 스펙 v5 User Login AC4(3회 실패 후 423)와 일치한다.
- 분류와 상태: 운영 메모(이슈 아님) / 발견 날짜 미상, 마지막 확인 2026-10-08 분류

### #10 `.env` 값의 따옴표를 벗기지 않음
- 문제 정의: `api-demo/config.py`, `playwright-demo/config.py`의 `_load_dotenv`가 `KEY="value"`의 따옴표를 벗기지 않아 값에 따옴표가 그대로 들어간다.
- 발생 배경: 설정 로딩 코드를 직접 구현했다. 현재 두 `.env`에는 따옴표, 주석, `export`가 없어 실제 문제는 없다.
- 추정 원인과 근거: python-dotenv 없이 직접 파싱하는 구현이다.
- 분류와 상태: 기술부채(설정) / 2026-10-04 사용자 결정: 현행 유지. 재검토 시점은 `.env` 값에 따옴표나 특수문자가 필요해질 때 / 발견 2026-10-04, 마지막 확인 2026-10-08 분류

### #17 데모 서버 DB가 주기적으로 리셋됨
- 발생 배경: API 스크립트 작성과 실행 중 발견. 카테고리와 상품 id가 실행 사이에 바뀐다(01M469... → 01M46C...). 재실행하면 통과한다.
- 추정 원인과 근거: 데모 서버의 주기적 DB 리셋.
