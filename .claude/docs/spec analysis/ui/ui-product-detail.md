# UI 분석: 상품 상세(수량 포함)

> 개요, 판단 기준, 우선순위별 리스크 목록: [00_ui-overview.md](00_ui-overview.md)

## 1. 기능 목적
| 기능 | 목적 |
|---|---|
| 상품 상세 | 상품 정보를 확인하고 수량을 선택해 장바구니에 담습니다. |

## 2. 핵심 흐름
1. 상품 상세
   - 확인 항목: 이름, 설명, 단가, 수량(기본 1, +/- 버튼, 직접 입력)
   - Add to Cart → 토스트 "Product added to shopping cart."

## 3. 리스크
- **R3** [불일치] 수량 상한
  - 스펙: "1~999,999,999로 clamp"
  - 소스: 99로 clamp + 경고 토스트 "You can order at most 99 of this product."
  - 근거: v5.md Product Detail AC7 vs `detail.component.ts` `MAX_QUANTITY = 99`, `cart.component.ts`도 99
  - 판단: 기대결과는 스펙(1~999,999,999) 기준으로 작성합니다.

## 4. 테스트 범위 (포함)
- 상품 상세: 정보 표시, 수량 +/-, 최소 1, 직접 입력(상한 포함), 장바구니 담기 토스트, 품절 시 버튼 비활성

## 5. TC 작성 입력값 (후보)
**D. 상품 상세**
- 후보 D-1: 수량 `+` 클릭 → 2, `-` 클릭 → 1
- 후보 D-2: 수량 1에서 `-` → 1 유지
- 후보 D-3: 직접 입력 `0`, 음수, 공란, 문자 → 1로 보정
- 후보 D-4: 직접 입력 `99`, `100`, 매우 큰 수
  - 스펙 기준: 1~999,999,999 범위로 clamp
  - 소스는 99로 clamp + 경고 토스트입니다. (R3)
  - 기대결과는 스펙 기준으로 작성합니다.
- 후보 D-5: 수량 3 지정 후 담기 → 장바구니 수량 3
- 후보 D-6: 품절 상품 상세 → Add to Cart 비활성, 수량 입력/버튼 비활성, "Out of stock"(빨강)
- 후보 D-7: 관련 상품 노출
