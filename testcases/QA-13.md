## 조건
- 로그인 상태

## 스텝
1. 메인 페이지 진입
2. 헤더 유저 메뉴 클릭 → 메뉴 노출
3. [Sign out] 버튼 클릭
   - [Sign out] 버튼 정상 노출
   - 로그아웃 정상 처리
   - 비로그인 상태의 메인 페이지(`/`) UI 노출 (유저 메뉴 사라짐)

## 비고
- 로그아웃 판정 기준: URL `/` + 유저 메뉴 비노출.
