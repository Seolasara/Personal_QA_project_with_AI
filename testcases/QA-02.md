## 조건
- 정상 계정 존재

## 스텝
1. [Email address] 필드에 도메인 없는 이메일 값 입력 → 입력한 값 그대로 노출
2. [Password] 필드에 정상 비밀번호 값 입력 → 마스킹 처리된 값 노출
3. [Login] 버튼 클릭 → "Email format is invalid" 얼럿 메시지 노출

## 비고
- 클라이언트 측 이메일 포맷 검증. 서버 요청 전에 차단된다.
