## 조건
- 없음

## 스텝
1. 메인 페이지 진입 → 전체 상품 리스트 정상 노출
2. 좌측 "By category" 필터 영역의 [Hammer] 체크박스 클릭
   - "Hammer" 체크박스가 체크 선택 상태로 노출
   - "Hammer" 카테고리 해당 상품 리스트만 노출

## 비고
- 자동화는 현재 체크 선택 상태만 검증. 리스트 필터링 결과 검증은 QA-08에서 커버.
